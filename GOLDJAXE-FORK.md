# GOLDJAXE — форк CloudCLI (siteboon/claudecodeui)

Форк холдинга GOLDJAXE поверх `siteboon/claudecodeui` (upstream, GPL v3).
CloudCLI = единая удалённая рабочая среда: Claude Code + MCP + скилы + браузер,
доступ преимущественно с телефона по Tailscale.

## Зачем форк

Часть доработок под холдинг невозможно сделать плагином (Plugin API изолирован:
`slot:'tab'`, не переопределяет встроенный композер, хуки, i18n, middleware ядра).
Такие правки живут в форке и параллельно отправляются PR в upstream на мерж
(гибрид «форк-до-мержа»).

## Roadmap (по волнам)

- **Волна 1** — нативный показ картинок в чате (`img`-override с авторизацией);
  прикрепление любых файлов, не только картинок.
- **Волна 2** — фикс мобильного переключателя уровня рассуждений (effort)
  *(снят при мерже v1.37.0 — upstream решил сам, см. реестр)*.
- **Волна 3** — перенос пользовательских настроек из `localStorage` в БД (per-user),
  голосовой apiKey — в шифрованный `user_credentials`, одноразовая миграция.
- **Волна 4** — модели `kimi-k3[1m]` и `claude-opus-5`; синхро настроек на любое
  изменение (автосинк); UI холдинга (сайдбар, мобильная шапка); автозапуск systemd.
- **Волна 5** — читаемый список сеансов: явное выделение активного сеанса,
  короткие ИИ-названия («предмет — действие») по первому запросу с откатом на
  сырой текст, подсказка с полным запросом, ручная перегенерация названия.
- **Волна 6** (после слияния upstream v1.37.3) — вечная сессия (365 дней +
  авто-продление, разлогин только на настоящий 401); закрепление чатов
  (`sessions.isPinned`) — и в «Разговорах», и внутри проекта; живое обновление
  вкладки «Разговоры» по `session_upserted`, без переключения вкладок;
  композер под телефон — микрофон в правом верхнем углу поля ввода (как в
  Claude Code), меню модели свёрнуто в иконку, панель снова в один ряд.
  Индикатор «в работе» и меню сеанса в «Разговорах» писать не пришлось —
  их закрыл сам upstream 1.37.3.
- **Волна 7** — подписка GPT в шлюзе CLIProxyAPI: модели `gpt-6-astra` и
  `gpt-6.1-sol` в каталоге Claude (уровень reasoning — суффиксом в id модели,
  иначе шлюз его игнорирует); генерация картинок прямо в чате — встроенный
  инструмент `generate_image` (gpt-image-2.5 через тот же шлюз, правки по
  референсу, картинка в карточке инструмента). Ограничение: с GPT-моделью в
  чате шлюз подсовывает свой генератор и теряет картинку — рисовать через
  Claude-модель (см. реестр §13.2).
- **Слияние upstream v1.37.4** (реестр §14) — апстрим сам сделал часть наших
  задач и сделал лучше: картинки по путям проекта в markdown (`MarkdownImage` +
  лайтбокс), стартовая проверка авторизации без перемонтирования приложения,
  тема «как в системе» в своём хранилище настроек. Наши части влиты поверх их
  кода, дубли сняты; попутно закрыты три старых дефекта форка — откат языка и
  возврат снятых звёзд проектов из-за двойной синхронизации настроек, пин
  внутри проекта, который не поднимал сессию наверх.
- **Отложено** — управление ПК (отдельный крупный проект).

Каждая правка: код → сборка/typecheck/lint/браузер-проверка → запись в реестре
→ commit.

## Upstream

```
git remote -v   # origin = https://github.com/siteboon/claudecodeui.git
```
PR отправляются в `siteboon/claudecodeui`. При обновлении upstream — merge
тега релиза в ветку доработок (`git merge vX.Y.Z`, как с v1.37.3 и v1.37.4) в
отдельном git worktree: боевой инстанс работает из этой папки (см. CLAUDE.md).
Расхождение минимизировать; что апстрим сделал сам и лучше — брать его версию,
наше поверх — помечать `Fork:` и вносить в реестр.
