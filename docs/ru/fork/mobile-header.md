# Мобильная шапка в одну строку

> Разделы реестра §4.2, §12.3. Часть [реестра правок форка](../fork-changes.md): номер § — постоянный адрес правки, по нему на эту страницу ссылаются код и коммиты.

## §4.2 Кнопка меню в шапке не сливается с лентой вкладок (мобила)

- **Слой:** UI · **Столкновение:** 🟢 (снят) · **PR:** решено upstream.
- **Что было:** на узком экране лента вкладок/плагинов подъезжала вплотную к
  кнопке-гамбургеру. Кнопка выносилась в отдельную зону с вертикальным
  разделителем и отступом справа.
- **Статус:** наша правка **снята при мерже v1.37.2** — upstream переработал шапку
  структурно (`MainContentHeader.tsx`): на мобиле заголовок и лента вкладок теперь
  в разных строках (`flex-col` → `sm:flex-row`), плюс появились кнопки прокрутки
  вкладок и градиенты по краям. Слипнуться кнопке с лентой больше негде, наш
  разделитель стал лишним. Оставлено как история — если upstream вернёт
  однострочную раскладку, смотреть сюда.
- **Файлы:** `src/components/main-content/view/subcomponents/MainContentHeader.tsx`.

## §12.3 Мобильная шапка — одна строка: заголовок + иконки вкладок

- **Слой:** UI · **Столкновение:** 🟡 (общие upstream-компоненты
  `WorkspaceHeader`/`WorkspaceTabs`) · **PR:** можно (чистое мобильное
  улучшение).
- **Симптом:** на телефоне шапка съедала две полосы: строка с названием чата и
  отдельная строка с пилюлями вкладок, где у активной была текстовая подпись
  («Чат») шириной с треть экрана.
- **Решение:** ниже `sm` подписи вкладок скрыты полностью (иконки + тултип +
  aria-label; активная подпись возвращается с `sm`, все подписи — с `lg`,
  как было), а шапка стала одной строкой на всех вьюпортах: гамбургер,
  заголовок (flex-1, truncate), лента вкладок (потолок 55% ширины, дальше её
  штатный горизонтальный скролл — плагин-вкладки не давят заголовок).
  Вертикальная экономия ~44px высоты чата. Десктопный расклад не изменился.
- **Файлы:** `src/modules/project-workspace/WorkspaceHeader.tsx`,
  `src/modules/project-workspace/WorkspaceTabs.tsx`. Проверено вживую
  (chrome-devtools, вьюпорты 390×844 и 1280×800 на тестовом инстансе).
- **Мерж-заметка (v1.37.4).** Апстрим добавил в строку заголовка индикатор
  потери соединения (#1485, `WorkspaceConnectionStatus.tsx`) и рассчитывал на
  свою двухстрочную мобильную шапку: ниже `sm` пилюля показывала подпись
  «Переподключение…», которая в нашей одной строке выдавила бы заголовок.
  Подпись теперь скрыта и ниже `sm` (`hidden xl:inline`; подсказка и
  live-region для скринридера остались). Переименование двойным кликом по
  заголовку (#1374) в однострочной шапке работает и идёт через наш
  `renameSessionById` (очистка `full_title` + рассылка) — проверено.
