# §27.5. Доставка по заданию в чате

**Что изменилось:** во встроенном исполнителе без каталога для нового набора по умолчанию выбран режим **«По заданию в чате»**. Адрес не обязан быть известен при вводе поля. Это не разрешение для Bash читать значение. У хода есть инструмент доставки, у владельца — последнее слово о получателе. Старые вложения и явно выбранные фиксированные назначения не расширяются.

1. Откройте замок, добавьте, например, поле `SERVICE_TOKEN` и его значение. Прикрепите к сообщению.
2. Напишите обычное задание: «Замени `SERVICE_TOKEN` в `/etc/example/service.env` на VPS проекта». Агент должен установить настоящее имя хоста и SSH-пользователя из несекретной информации проекта или уточнить их. Значение ему не нужно.
3. CloudCLI показывает полный предложенный адрес и **имена именно тех полей**, которые получатель получит. Сверьте и подтвердите карточку в исходной вкладке. Не подтверждайте посторонний или неоднозначный адрес. Без согласия передача не начинается; отказ завершает попытку.
4. В чат поступает только статус. Успешная запись в файл и перезапуск службы — разные действия. Инструмент не перезапускает службы; не нужно читать значение обратно для проверки.

## Варианты назначения

| Назначение | Что происходит |
|---|---|
| `ssh://service@host:22/etc/example/service.env` | По SSH обновляются одноимённые переменные существующего плоского systemd `EnvironmentFile`; другие строки сохраняются. Приёмник CloudCLI устанавливать не нужно. Требуются Linux, `/usr/bin/python3`, фактический DNS/IP, известный ключ хоста и уже работающий доступ по SSH через `keychain`. Без `sudo`, `ssh_config`-алиасов, проброса агента, пользовательских команд и автопринятия ключей. |
| `project:config/.env` | Атомарная запись выбранных полей в существующий игнорируемый Git файл окружения **внутри проекта этого чата**. На карточке показан полный путь. Корень берётся из БД сеанса. |
| `https://host/path` | Единственный `POST` на утверждённый точный HTTPS-адрес: тело — JSON-объект `{имя: значение, …}`. Только для сервисов, которые ожидают такой запрос. Без credentials в URL, query, добавочных заголовков, повторов, перехода по `Location` и возврата содержимого ответа. `2xx` означает, что запрос принят, не что сервис уже применил секрет. |

Для записи нужны реальные права учётной записи. SSH-приёмник отказывается писать по ссылке, в небезопасный каталог, файл с неожиданными правами (разрешены `0600`/`0640` владельца) или неоднозначным синтаксисом. Он записывает весь набор одним переименованием и выдаёт квитанцию без значений. При обрыве связи результат может остаться неизвестным — автоповтора нет. Записанный файл **содержит** значения и должен быть закрыт от постороннего чтения. HTTPS-получатель тоже получает сами выбранные значения: перенос не делает чужой сервис доверенным.

## Как устроено

Метка `chat-destination` закреплена в AES-GCM AAD браузерного конверта. Только соответствующий прямой Claude-ход получает `deliver_protected_fields(destination, fields)`. Аргументы содержат адрес и имена, но не значения. Сервер разбирает предложение один раз; именно этот адрес и набор имён показываются на карточке и передаются исполнителю. Текст, системное разрешение SDK и «всегда разрешать» не дают права на доставку.

Ответ `chat.protected-delivery-decision` принимается только для ожидающего запроса исходного аутентифицированного WebSocket, сеанса и хода. До согласия нет расшифровки для доставки, SSH-запроса, записи файла или сетевого POST. При разрыве связи до согласия, истечении, отзыве или завершении хода доступа нет. Ранее начатую и подтверждённую запись нельзя отменить задним числом. В hosted-режиме с автоматической идентификацией пользователя свободное назначение не предлагается. Установка собственного ограниченного каталога, как и раньше, заменяет встроенный выбор.

**Ключевые файлы:** `server/modules/protected-data/{mcp,chat-destination,executor,ssh-env-delivery,ssh-env-writer}.ts`, `server/modules/protected-data/delivery-approval.ts`, `chat-websocket.service.ts`, `claude-runtime.provider.ts`, `ProtectedDataForm.tsx`, `ProtectedDeliveryPanel.tsx`.
