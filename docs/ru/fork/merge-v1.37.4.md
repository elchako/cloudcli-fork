  прогонов папки. С нашим кодом и только их файлами — 0 из 4; после правки —
  0 из 4 и с нашими. Кандидат в PR.

## §14.6 На заметку

- **Предупреждение о ключе API** (#1375) — в «Настройки → Агенты → Claude»
  может появиться жёлтая плашка, если рядом с токеном шлюза лежит ещё и
  OAuth-логин. Для нашего шлюза это ожидаемо; в чат она не выходит.
- **Подпись модели под ответом** (#1391) показывает семейство (`Opus`,
  `Sonnet`, `Fable`), незнакомые id — как есть (`gpt-6-astra`, `kimi-k3`).
- **Codex: GPT-6 Sol / GPT-6 Luna** (#1435) — модели провайдера Codex, не путать
  с нашими `gpt-6.1-sol`/`gpt-6-astra` у Claude через шлюз.
- **Библиотека кастомных моделей** (`provider_models`, #1418 — теперь с
  уровнями effort) — возможная замена части захардкоженного каталога (§1)
  без правок ядра; отдельная задача, суффикс effort для шлюза ([§1.3](gpt-gateway.md)) пришлось
  бы сохранить.
- **Выкатка — 2026-10-09, по команде владельца.** В основной папке
  `npm install --include=dev && npm run build`; перед рестартом новая сборка
  поднята на отдельном порту на **копии** боевой БД (миграции на реальных
  данных, старт, ответ API) — чтобы сбой не уронил службу в цикл
  перезапусков. Рестарт — `systemd-run --user --on-active=…` (отдельный
  юнит, вне cgroup службы): сессия агента живёт внутри службы и обрывается
  рестартом, а так успевает доложить. После рестарта служба поднялась с
  первого раза (миграции на боевой БД прошли), отдаёт сборку 1.37.4.
- **Публикация — 2026-10-09, по команде владельца:** ветка в GitLab
  (`goldjaxe`, `git.q-standard.com`) и в зеркало GitHub для команды
  (`git publish`, перемотка вперёд без force). Коллеги обновляются
  `./scripts/update.sh`; после обновления у них, как и здесь, применятся
  миграции апстрима (колонки effort в `provider_models`).
