# Свои модели через библиотеку: «Польза.ai»

> Раздел реестра §1.5. Часть [реестра правок форка](../fork-changes.md): номер § — постоянный адрес правки, по нему на эту страницу ссылаются код и коммиты.

## §1.5 «Польза.ai» через шлюз и штатную библиотеку моделей

- **Слой:** эксплуатационная настройка, **не доработка кода** ·
  **Столкновение:** 🟢 (нет правок `src/`/`server/`) · **PR:** не требуется,
  используется штатный механизм upstream.
- **Что:** 09.10.2026 на CLIProxyAPI 8.0.4 добавлено отдельное подключение `polza`
  в `api-keys.openai-compatibility`, адрес `https://polza.ai/api/v1`, модели
  `xiaomi/mimo-v2.6-pro` и `qwen/qwen3.8-flash`. Прежние подключения, клиентские
  ключи и `ANTHROPIC_BASE_URL` CloudCLI сохранены. Ключ «Польза.ai» только на
  шлюзе, не в репозитории и не в настройках CloudCLI.
- **CloudCLI:** обе модели добавлены штатным `POST /api/providers/claude/models`
  в таблицу `provider_models`: «MiMo V2.6 Pro — Польза.ai» и
  «Qwen 3.8 Flash — Польза.ai». Встроенный список не менялся; добавление на
  шлюзе само по себе не добавляет модель в CloudCLI. После настройки обновить
  открытую страницу клиента.
- **Проверка:** вызов инструмента, результат инструмента и потоковый ответ через
  Anthropic `/v1/messages`; настоящий Claude CLI с каждой моделью успешно
  прочитал тестовый файл через `Read`. Существующий Opus также отвечает.
  Qwen отвергает принудительный `tool_choice` (`400`), штатный автоматический
  выбор работает. Effort отдельно не объявлен; `[1m]` не добавлен, поэтому
  большее окно из каталога «Польза.ai» не включено в Claude CLI.
- **Где смотреть:** на шлюзе `/root/cliproxyapi/config.yaml` (права `600`);
  библиотека в `~/.cloudcli/auth.db`, `provider_models`. Штатная реализация —
  `server/modules/providers/provider.routes.ts`,
  `server/modules/providers/services/provider-models.service.ts`,
  `src/modules/chat/modals/ModelLibraryPanel.tsx` (эти файлы не менялись).
- **Откат:** удалить подключение `polza` и две записи через библиотеку моделей.
  Исходный конфиг сохранён в
  `/root/cliproxyapi/config.before-polza.20261009T184555Z.yaml`; восстанавливать
  целиком только при отсутствии более поздних правок. Перезапуск и пересборка
  при добавлении не потребовались.
- **Мерж:** модели живут в эксплуатационной БД, не добавлять их повторно в
  `CLAUDE_PREDEFINED_MODELS`. Для нового инстанса настроить шлюз и библиотеку
  отдельно; перенос git-ветки сам по себе эти записи не переносит.
