# Обновление upstream v1.37.8 (2026-11-08)

> Раздел реестра §19. Часть [реестра правок форка](../fork-changes.md).

## §19 Объём обновления

- **Слой:** client + server + зависимости · **Столкновение:** 🟡 ·
  **PR:** слияние upstream в форк, отдельный PR не открыт.
- Upstream: тег `v1.37.8`, коммит `2053f3d7`; предыдущая база — `v1.37.6`.
  Включены также изменения v1.37.7. Слияние выполняется на ветке
  `merge/upstream-v1.37.8` в отдельном worktree, основной каталог получает
  результат только `merge --ff-only`.
- **Полезное:** уточнение в работающий Claude-ран (Steer), побочные вопросы
  своей сессией провайдера, видимые MCP elicitation; ручные клики/ввод в Browser,
  MCP `browser_upload_file`, скачивание оригинала из бинарного просмотрщика;
  отдельные Archive/Delete, мобильный Fork и переименование двойным щелчком.
- **Исправления:** Enter экранной клавиатуры — перенос строки, компактная строка
  кнопок с большим счётчиком токенов, ссылки с URL-кодированной кириллицей,
  fallback копирования пути без Clipboard API; исправления OpenCode.
- **Зависимости:** Claude Agent SDK 0.3.311, Codex CLI/SDK 0.166.0. Наш прямой
  `zod` и скрипт обновления форка сохранены. При установке Electron-download
  вернул HTTP 504; повтор с `ELECTRON_SKIP_BINARY_DOWNLOAD=1` успешен. Это
  веб-инстанс: desktop-бинарник не проверялся и для выкатки не требуется.

## §19.2 Пересечения и решения

Разрешены 10 конфликтных файлов; ни один общий компонент не заменён целиком
вариантом одной стороны.

| Участок | Решение |
|---|---|
| `package.json`, `package-lock.json` | Новые SDK upstream, сохранены наши дополнительные зависимости и update-скрипт |
| `claude-runtime.provider.ts` | Image MCP и upstream `extraArgs: replay-user-messages` вместе; сохранены GPT effort/930k, Kimi endpoint, любые вложения и тип нативного query/interrupt; приняты steer, elicitation и native side questions |
| `provider.routes.ts` | Оба сервиса: наш навигатор промптов и upstream side questions |
| `ChatInterface.tsx`, `ChatComposer.tsx` | Новый send menu и пропсы возможностей; компактная панель без часов и справочной строки, микрофон в поле, очередь надиктовок, блокировка отправки при распознавании сохранены |
| `useChatComposerState.ts` | Оба импорта: поддержка любых файлов и побочные вопросы; UUID steer upstream; наши лимиты файлов; восстановление очереди без дублирования файлов. Новый steer также соблюдает снимок черновика — [§19.1](attachments.md) |
| `Markdown.tsx` | Декодирование пути upstream перед нашим лайтбоксом; повторное объявление `filePath` удалено. Тест ссылки с кириллицей, пробелом и суффиксом строки |
| `SessionOptions.tsx`, `SidebarSessionItem.tsx` | Пины, полные названия, перегенерация и выделение вместе с раздельными Archive/Delete, mobile Fork и double-click rename |

Автослитые sidebar/controller и общие файлы сверены с чистым тегом: живые
«Разговоры», навигатор, голос/сводка, актуальное название в push, чтение по
`CLOUDCLI_READ_ROOTS`, ограничения assets/cwd и настройки авторизации сохранены.
Новые ключи `user_preferences` не добавлялись в наш `userSettingsSync`.

Новый секрет подписи webhook адаптирован к обязательному `sealSecret` —
[§20](webhook-notifications.md). Протокол, фильтр исходящих событий и политика
URL upstream не изменены; канал сам по себе не включается.

  прежняя адаптация теста в форке сохранена.

  новых диагностик по сочетанию файл/правило/сообщение нет.
- Полный клиентский набор с `NODE_ENV=test`: **164 файла, 1236 тестов — успешно**.
  Новые upstream-тесты адаптированы к контексту/очереди голоса и форковым props.
- Полный серверный набор через `tsx`, отдельные `HOME`/`DATABASE_PATH`,

## §19.4 Выкатка и независимая проверка рестарта

Владелец явно согласовал сборку и перезапуск в исходном запросе 2026-11-08.
Порядок после проверок: коммит → ff-only основной ветки → push `goldjaxe` →
`git publish` → согласованный SQLite backup и сохранение `secret.key` →
установка зависимостей/сборка основного каталога → явный рестарт службы.

Сессия агента работает внутри `cloudcli-fork.service`, поэтому рестарт может
оборвать её. Проверку выполняет независимый процесс systemd: фиксирует новый
MainPID, активность службы, HTTP и версию 1.37.8; результат сохраняется в
`~/.cloudcli/deployments/v1.37.8-20261108/result.txt`. Этот файл и журнал службы
— факт выкатки; наличие коммита или пуша само по себе рестарт не доказывает.
Резерв БД и мастер-ключ не публикуются и не попадают в Git.

Временный стенд останавливается по проверенным PID/cwd/порту; оба worktree
удаляются только после проверки вхождения HEAD в целевую ветку и сохранности
игнорируемых файлов. Скриншоты стенда остаются вне них в
`/tmp/cloudcli-v1.37.8-smoke/`.
