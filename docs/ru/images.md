# Картинки прямо в чате

Агент умеет рисовать и править картинки встроенным инструментом `generate_image`.
Модель изображения выбирается отдельно от модели разговора.
Технические детали — [§13](fork/image-generation.md).

## Как пользоваться

Попросите в чате:

- «Набросай идею баннера: золотой топор на тёмно-синем фоне» — режим «Черновик»;
- «Нарисуй иллюстрацию для статьи» — режим по умолчанию из настроек;
- «Сделай финальную версию второго варианта» — режим «Финал»;
- «Сделай тот же значок, но на белом фоне» — прошлая картинка как референс;
- «Перерисуй логотип в монохроме» + прикреплённая картинка.

Картинка появляется в карточке инструмента. Под ней — запрошенные модель,
режим, качество и время. Если API сообщил модель ответа, она подписана отдельно:
запрошенные параметры не выдаются за подтверждённые шлюзом.
Файл сохраняется в `~/.cloudcli/assets/…-generated.png`; попросите скопировать
его в проект, например в `public/icons/`.

Уточняйте формат (квадрат / горизонталь / вертикаль), прозрачный фон и желаемые
правки. Явная просьба о `low`/`medium`/`high`/`auto` может переопределить качество
профиля. Параметр качества не гарантирует скорость, цену или итоговый результат:
его поддержку определяет API.

## Настройки профилей

**Настройки → Внешний вид → Генерация изображений.** Для каждого режима
«Черновик», «Обычный», «Финал» выберите модель GPT Image из API и качество.
Задайте режим по умолчанию и нажмите «Сохранить профили».
Выбор хранится для аккаунта на сервере, работает на всех устройствах и
применяется к следующему вызову инструмента без перезапуска рана.

«Обновить список» запрашивает каталог заново и не стирает несохранённый выбор.
Исчезнувшая модель остаётся видна с предупреждением. При генерации такой режим
даст понятную ошибку, но не запустит другую модель автоматически. Недоступность
самого каталога не сбрасывает сохранённые ID.

Названия Flare и Sunburst **не означают автоматически** «быстро» и «качественно».
Различия шлюз в каталоге не описывает. Можно назначить одну модель всем профилям
с разным качеством. Новые версии GPT Image появляются из API без правки кода;
другие семейства, включая Nano Banana, пока не подключены.

До первого сохранения все профили используют `CLOUDCLI_IMAGE_MODEL`, а без
этой переменной — `gpt-image-2.6`; качества — low / auto / high. Если такой
модели нет в вашем API, выберите доступную в меню. Существующий явный выбор
никогда не мигрирует на другую модель без пользователя.

## Модель разговора и ограничения

**Рисовать лучше через Claude-модель**: у GPT шлюз может подмешать собственный
генератор, результат которого теряется при переводе в Anthropic-формат.
Настройки профилей не исправляют эту особенность шлюза
([§13.2](fork/image-generation.md)).

- Нужны шлюз `ANTHROPIC_BASE_URL` и токен в окружении или `~/.claude/settings.json`.
  Без шлюза инструмента нет; `CLOUDCLI_IMAGE_GEN=off` выключает его.
- `CLOUDCLI_IMAGE_MODEL` задаётся в `Environment=` службы или в `env` файла
  `~/.claude/settings.json`; сохранённые профили пользователя важнее.
- Референсы — только PNG/JPEG/WebP до 20 МБ из cwd проекта или `~/.cloudcli/assets`;
  ссылки наружу, включая симлинки, не разрешены.
- Генерации расходуют квоту/бюджет API. Несколько моделей для сравнения запускаются
  только по отдельной просьбе. Автоматического повышения режима или платного
  повторения после ошибки нет.
