# CloudCLI (форк GOLDJAXE) — документация

**Что это.** Веб-интерфейс к CLI-агентам Claude Code, Cursor CLI и Codex
(upstream `siteboon/claudecodeui`) с доработками холдинга GOLDJAXE. Основной
сценарий — единая удалённая рабочая среда, доступ с телефона по Tailscale.

## Как пользоваться документацией

Запрос → это оглавление → две-четыре нужные страницы → ответ. Одна тема — одна
страница. У каждой страницы есть frontmatter (`title`, `type`, `tags`,
`description`, `updated`), а внизу — «Связанные страницы». Нужную страницу можно
найти поиском, не открывая файлы:

```bash
rg '^description' docs/ru            # что лежит на каждой странице
rg -l '§4.9' docs/ru/fork            # где раздел реестра «§4.9»
rg -l '^tags:.*голос' docs/ru        # страницы по тегу
```

## Правила ведения

- **Поменял поведение — поменял страницу тем же коммитом** и обновил `updated`.
  Правки кода форка, кроме того, обязательно попадают в
  [реестр](fork-changes.md#регламент-ведения).
- **Один факт — одна страница.** Остальные страницы ссылаются на неё, а не
  пересказывают.
- **Новая тема — новая страница** с frontmatter и «Связанными страницами», плюс
  строка в это оглавление (правки форка — в оглавление реестра).
- **Страница перевалила за ~300 строк или описывает две темы — раздели её.**
- **Ссылки только относительные**, от текущего файла: так они работают и в
  Gitea, и в GitHub-зеркале.
- **`type` в frontmatter:** `index` — оглавление, `guide` — пользователю, `ops` —
  эксплуатация, `dev` — разработка, `reference` — справочник, `fork-change` —
  правка форка, `fork-merge` — слияние upstream, `plan` — план работ.
- **`CLAUDE.md` — только инструкции и ссылки.** Справочные данные (карта кода,
  эндпоинты, переменные, история) живут здесь, в документации: `CLAUDE.md`
  грузится в каждую сессию агента целиком.
