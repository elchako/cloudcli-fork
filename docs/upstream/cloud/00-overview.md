# CloudCLI Cloud — Managed Cloud Environments for AI Agents

## Overview

CloudCLI Cloud is a fully managed platform providing persistent cloud containers for AI coding agents. Unlike self-hosted versions, it eliminates infrastructure management needs.

## Key Differences from Self-Hosted

The self-hosted variant requires running CloudCLI UI on your personal machine or managed server, keeping sessions active locally. CloudCLI Cloud hosts both the interface and agent sessions in the cloud, enabling device switching, team handoffs, and overnight execution without local resources.

## Core Features

- **Persistent Cloud Environments**: Independent agent sessions running continuously
- **Multi-Device Access**: Seamless switching between laptop, browser, IDE, and SSH
- **Team Collaboration**: Shared configurations, MCP servers, and isolated developer access
- **Integration Options**: n8n nodes, REST API, and webhook support
- **Open Source Alternative**: AGPL-3 licensed self-hosting available

## Getting Started

Users can sign up directly at cloudcli.ai without installation. The platform supports various AI tools including Claude Code, Cursor, Codex, and Gemini, requiring only personal AI subscriptions (Claude Pro, OpenAI API keys, etc.).

## Platform Capabilities

- Background agent execution for overnight processing
- Mobile access for session management
- Custom containerized development environments
- SSH integration and IDE connectivity

The documentation supports developers seeking both managed solutions and self-hosted deployment options.
