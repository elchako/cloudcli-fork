# File Explorer & Editor — CloudCLI UI

## Overview

CloudCLI UI provides an integrated file management system that allows developers to browse, edit, and manage project files without switching applications.

## Browsing Files

The left sidebar displays the complete directory structure. Users can expand/collapse directories, open files in the editor, and perform basic file operations including creation, renaming, and deletion.

## Editing Files

The editor supports syntax highlighting for multiple languages including JavaScript, TypeScript, Python, CSS, HTML, JSON, and Markdown through CodeMirror integration. Changes automatically save to disk, and a diff view lets developers review modifications before accepting them.

## Working With Agent Changes

When an AI agent modifies files, CloudCLI displays an inline diff. This allows developers to review and approve or reject individual file edits directly within the interface.

## Accessing Files on Mobile

The file explorer functions fully on mobile devices. The sidebar automatically collapses on smaller screens, with a file icon in the bottom navigation providing access.
