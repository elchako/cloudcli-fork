# Mobile App — Use Claude Code from Your Phone | CloudCLI

## Overview

CloudCLI provides mobile-optimized access to AI coding agents including Claude Code, Cursor, Codex, and Gemini. The platform adapts seamlessly to smartphones while maintaining full feature support.

## Accessing on Mobile

**Self-hosted installations**: Connect via `http://[your-machine-ip]:3001` on the same network—no additional setup required.

**CloudCLI Cloud**: Access through `cloudcli.ai` from any device browser, with a native app currently in development.

## Touch-Optimized Interface

The mobile experience includes:

- **Bottom navigation bar** for thumb-accessible Chat, Files, Git, and Settings
- **Collapsible sidebar** to maximize content viewing space
- **Swipe gestures** for intuitive section navigation
- **Touch-friendly inputs** supporting virtual keyboards across chat, file editing, and commit functions

## Progressive Web App Support

Users can add CloudCLI to their home screen for native app-like functionality:

**iOS**: Open in Safari → Share icon → "Add to Home Screen"

**Android**: Open in Chrome → Menu → "Add to Home Screen" or "Install App"

## Feature Support Matrix

All core features function on mobile devices, including chat, terminal, file exploration and editing, Git operations, MCP management, and session handling.
