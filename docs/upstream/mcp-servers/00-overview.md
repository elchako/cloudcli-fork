# CloudCLI Cloud — Managed Cloud Environments for AI Agents

## Overview

CloudCLI Cloud is a fully managed platform that provides persistent cloud environments for AI coding agents. Unlike self-hosted versions, it requires no server setup or maintenance.

## Key Differences from Self-Hosted

The self-hosted CloudCLI UI runs locally on your machine, meaning sessions remain tied to that device. In contrast, the cloud version allows both the interface and agent sessions to run remotely, enabling "you can close your laptop, switch devices, hand off to a teammate, or let an agent run overnight" without interruption.

## Core Features

The platform offers:
- Persistent containerized cloud environments for each session
- Multi-device accessibility across browsers, phones, VS Code, and SSH
- Team collaboration with shared MCP servers and isolated developer configurations
- Integration capabilities via n8n nodes, REST APIs, and webhooks
- Open-source AGPL-3 UI available for self-hosting

## Getting Started

Users can sign up at cloudcli.ai without installation. The service integrates with existing AI subscriptions (Claude Pro, Cursor, OpenAI API keys, etc.).

## Additional Resources

The platform supports background coding agents, mobile access for Claude Code and Codex, and shared team environments with custom configurations.
